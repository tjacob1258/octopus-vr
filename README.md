# Octopus VR (prototype)

VR & Perception final project prototype. You play a first-person octopus in a
greyscale underwater world. The octopus senses colour through its skin: touch a
rock or coral with a tentacle tip and that tentacle takes on the object's real
colour. Hold the touch for a moment and the whole octopus camouflages.

**Play:** https://tjacob1258.github.io/octopus-vr/ (click the game once to start)

## Controls (desktop browser)

| Keys | Action |
|---|---|
| Arrow keys | Swim forward / back / left / right |
| U / O | Sink / rise (Shift = faster) |
| Mouse | Look (click to capture, Esc to release) |
| I J K L | Right tentacle |
| W A S D | Left tentacle |
| G | Toggle goggles |
| R | Reset tentacles and colour |

## VR (Meta Quest 3)

Open the link in the Quest browser and press **Enter VR**.

| Control | Action |
|---|---|
| Controllers | Each one steers a tentacle; reach out to touch things |
| Left thumbstick | Swim where you're looking |
| Right thumbstick | Turn (left/right), rise/sink (up/down) |
| A / X button | Recentre your view inside the octopus |

Built with Blender and Godot 4.7 (web export).
